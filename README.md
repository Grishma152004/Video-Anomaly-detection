# Video-Anomaly-detection
Surveillance of images using CNN 
🚨 Video Anomaly Detection using Deep Learning
An unsupervised AI system to detect abnormal activities in CCTV footage using 3D CNN Autoencoders.

🚀 Overview
The system is trained on normal pedestrian movement. It detects anomalies (like cycles, vehicles, or accidents) by identifying high Reconstruction Error in the video frames.

🛠 Tech Stack
Framework: TensorFlow / Keras
Computer Vision: OpenCV
Model: Conv3D Autoencoder
Data: UCSD Ped2 Dataset
📈 Key Results
The model successfully flags abnormal frames with a visual red alert on the screen.

🔗 How to run
Open the .ipynb file in Google Colab
